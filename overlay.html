      A · Make a Twitch app (one time)

      1. Open dev.twitch.tv/console/apps, signed in as KruuuuZe. Twitch asks you to turn on two-factor login first if you haven't.
      2. Register Your Application. Name: anything, e.g. kruuuuze-overlay. OAuth Redirect URL: http://localhost. Category: Broadcaster Suite. Client Type: Public.
      3. Open the app with Manage and copy the Client ID.

      B · Grab your token

      After you click Authorize, Twitch sends you to a page that won't load. That's expected. Copy the whole web address from the address bar and paste it here.

      C · Add to OBS (on your PC)

      1. Put overlay.html somewhere it will stay, e.g. C:\Stream\overlay.html.
      2. In OBS: Sources → + → Browser. Leave “Local file” unchecked.
      3. URL: file:///C:/Stream/overlay.html followed by the ?token=… part from step B.
      4. Width 1920, Height 1080. Turn on Refresh browser when scene becomes active.
      5. To place it on screen, add &demo to the end of the URL. Fake predictions will loop until you remove it.
      Extra options for the end of the URL: &pos=bottom moves the card to the bottom. &scale=1.2 makes it bigger. &results=30 sets how many seconds the results stay up.

      Keep this URL off stream, because it contains your token. The token can only read predictions. Twitch tokens expire after a while. When the overlay says the token expired, redo step B.
